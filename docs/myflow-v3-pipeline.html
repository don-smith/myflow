Cross-Cutting Practices

epiphany-tabling

Active during stages 2–4. Anything not trivially in-scope → personal repo tabled file. Resolve in stage 5 group 3.

capturing-learnings

Checkpoint after stages 1, 2, 4, 5. Once is a moment; twice is a pattern. Promote twice-seen patterns to skills/memory/runbooks.

verification-before-completion

Before any completion claim — run the verification command fresh, read output, cite evidence. No shortcuts.

stage-boundary restarts

Fresh sessions expected at each stage boundary. Artifacts are the primary handoff mechanism. Resume from artifact path + recommended next-stage command.

create / resume handoff

Backup for mid-stage pauses. Artifacts are the primary handoff. Use create/resume only when context is high and you must stop mid-stage.

telemetry & replay checkpoints

Every stage artifact carries a Context Checkpoint (in-progress state) and a Rehydration Manifest (finalized handoff). Artifacts are self-contained.
