# Glossary

- **Invoice**: Billing's customer-facing statement of amount due.
- **Charge**: Billing's attempt to collect an invoice amount.
- **Debit**: Ledger entry in the accounting context. It is not an alias for charge.
- **Dispatch**: Fulfillment's process for preparing and handing off a parcel.
- **Shipment**: Historical same-context name still present in fulfillment code. Use dispatch for the process.
