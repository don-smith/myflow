# Capturing Learnings

Run `node skills/myflow/scripts/resolve-repository-map.mjs discover --cwd <git-root>` first. Read the selected map for repository-owned destinations; do not assume a personal store or a mandatory memory system.

At an artifact checkpoint, inspect the current workstream evidence and decide only when there is an observation worth preserving:

- **first occurrence:** table a concise follow-up in the mapped/workstream destination or consciously drop it;
- **repeated pattern:** promote it to an existing skill, runbook, repository document, or mapped backlog when evidence justifies it;
- **already documented:** update the authoritative existing source rather than creating another file.

Record the decision and destination in the stage checkpoint or closeout summary. `writing-retros` is optional process reflection, not a required closeout gate.
