# Epiphany Tabling

Run `node skills/myflow/scripts/resolve-repository-map.mjs discover --cwd <git-root>` first. Record an out-of-scope observation in the mapped repository backlog or the current workstream's explicit follow-up section; do not assume a global tabled-file helper.

Each entry states the observation, enough context to resume it cold, and an intended destination. At the next appropriate checkpoint, either act when in scope, route it to a new Scope/backlog/learning artifact, or consciously drop it. Close records unresolved follow-up destinations; it does not require an empty table.
