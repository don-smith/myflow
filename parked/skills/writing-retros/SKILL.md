# Writing Retros

Run `node skills/myflow/scripts/resolve-repository-map.mjs discover --cwd <git-root>` first. A retrospective is optional process evidence, never a Close prerequisite. Use a mapped repository or personal location only when the developer and evidence justify one.

Keep it short and specific:

1. keep doing;
2. stop or change;
3. promote to an existing artifact, if a repeated pattern warrants it;
4. deliberate drop or follow-up destination.

Link the accepted plan, validation report, and closeout summary. Do not invent a memory system, status ritual, or fixed personal-store path.
